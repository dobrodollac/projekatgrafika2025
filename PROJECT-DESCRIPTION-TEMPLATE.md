# Strumfovi

162/2021 - Lenka Dobrodolac
Na sceni se nalaze likovi iz crtanog filma Strumfovi: Strumfeta, Velikki Strumf, Bubalo i Gargamel. Gargamel se
pojavljuje i veliki strumf ide da obavesti Strumfetu i Bubalala da treba da nestanu.

## Controls

W -> Kamera se pomera unapred.  
S -> Kamera se pomera unazad.
A -> Kamera se pomera levo.
D -> Kamera se pomera desno.
E -> Strumfovi nestaju sa scene.
G -> Pojavljuje se Gargamel i Veliki Strumf se krece ka Strumfeti i Bubalu.
ESC -> Izlazak iz aplikacije.
F12 -> Otvara prozor od GUI.
